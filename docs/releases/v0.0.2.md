Foxmind v0.0.2 新增自定义 AI 服务，可使用狐森或其他兼容 OpenAI 的接口生成网页与选区摘要。

### 自定义 AI 服务

- 在设置或安装引导中选择「自定义 AI 服务」，填写 API 地址、API Key 和模型 ID。
- 支持读取服务的模型列表，也可直接填写模型 ID。
- 支持本地与自托管服务；服务无需身份验证时，API Key 可留空。
- 狐森和自定义服务分别保存配置，切换后可恢复之前的密钥与模型。
- 设置与侧边栏显示当前摘要服务。切换服务或修改 API 地址后，需要重新开启网页内容授权。

### 使用体验

- 完善多个设置页之间的配置保护，避免较早的响应覆盖新配置。
- 修复设置通知延迟到达时，误取消使用最新配置的摘要任务的问题。
- 更新简体中文、英语安装引导与隐私政策，说明第三方 AI 服务的直接请求方式。
- 摘要存档继续保存在当前浏览器，切换账户或 AI 服务后仍可搜索和查看。

### 安装与升级

- 下载并解压 [foxmind-0.0.2.zip](https://github.com/Foxmori-Official/Foxmind/releases/download/v0.0.2/foxmind-0.0.2.zip)。
- 使用 Chrome / Edge 116 及以上版本，在扩展管理页开启开发者模式，选择「加载已解压的扩展程序」，加载包含 manifest.json 的文件夹。
- 已安装用户可将新版文件覆盖到原扩展目录，在扩展管理页重新加载，并刷新已打开的网页。
- 在设置中选择 AI 服务并配置模型，开启「网页内容授权」，再从侧边栏主动请求摘要。
