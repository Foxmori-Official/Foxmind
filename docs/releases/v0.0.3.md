Foxmind v0.0.3 改进狐森密钥连接与摘要等待，支持更顺畅的手动配置和慢模型摘要。

### 账户与密钥

- 使用狐森通用密钥接口创建密钥，默认名称为 Foxmind，可手动填写或与其他客户端共用。
- 账户与套餐分组按需读取，已配置的有效密钥可直接用于摘要，主站退出登录后仍可使用。
- 保存密钥成功后立即反馈，模型列表独立加载。等待期间新保存的配置会受到保护。

### 摘要体验

- 摘要和模型列表的等待上限统一为 10 分钟，适用于耗时较长的模型。
- 整页与选区摘要生成时，原按钮显示「取消摘要」，点击即可中断请求。
- 本机摘要存档支持切换账户后搜索、打开与查看原文依据。

### 安装与升级

- 下载并解压 [foxmind-0.0.3.zip](https://github.com/Foxmori-Official/Foxmind/releases/download/v0.0.3/foxmind-0.0.3.zip)。
- 使用 Chrome / Edge 116 及以上版本，在扩展管理页开启开发者模式，选择「加载已解压的扩展程序」，加载包含 manifest.json 的文件夹。
- 已安装用户可将新版文件覆盖到原扩展目录，在扩展管理页重新加载，并刷新已打开的网页。
