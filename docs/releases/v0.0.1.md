Foxmind v0.0.1 是首个公开版本，在浏览器侧边栏提供网页摘要、选区摘要和资源下载联动。

### 摘要与网页导出

- 点击工具栏图标打开或关闭侧边栏，点击「总结当前页」后生成摘要。切换标签页后保留已完成的结果。
- 选区摘要独立展示在整页摘要与资源之间，可同时查看两种结果及原文依据。
- 支持将当前网页导出为 HTML 或 Markdown。HTML 保存静态页面，外部图片与样式沿用原地址。
- 摘要存档支持搜索、打开详情、删除单条和清空记录。普通窗口的存档保存在当前浏览器，切换狐森账户后仍可查看。

### 账户与下载

- 首次安装提供简体中文、英语引导，连接狐森账户并获取专用密钥，也可填写主站已有密钥。
- 建钥和模型响应写入前检查配置版本，保留用户在另一设置页刚保存或移除的密钥。
- 通过 Foxdown 服务器地址与可选 Web API Token 连接下载服务，发现网页附件与有权读取的媒体资源。

### 安装与升级

- 下载并解压 [foxmind-0.0.1.zip](https://github.com/Foxmori-Official/Foxmind/releases/download/v0.0.1/foxmind-0.0.1.zip)。
- 使用 Chrome / Edge 116 及以上版本，在扩展管理页开启开发者模式，点击「加载已解压的扩展程序」，选择包含 manifest.json 的文件夹。
- 完成账户与模型配置，开启「网页内容授权」，再从侧边栏主动请求摘要。
- 覆盖升级时，将新版文件复制到原扩展目录，在扩展管理页重新加载并刷新已打开的网页。

安装包由 GitHub Actions 构建，校验值见 [SHA256SUMS.txt](https://github.com/Foxmori-Official/Foxmind/releases/download/v0.0.1/SHA256SUMS.txt)。

发布流程执行类型检查、8 项自动化测试与 Chromium 浏览器验收，覆盖双设置页并发写入、侧栏开关、摘要和原文依据、导出、存档搜索及下载转交。
