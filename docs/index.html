下载 Foxmind 安装与使用

适用于 Chrome 和 Edge · 简体中文 / English

摘要有原文可查

整页与选区摘要独立展示，展开要点查看对应原文。切换标签页后，已完成的结果仍然保留。

读过的内容，再找到

在本机存档中搜索标题、网址、摘要与原文依据。打开记录回看，也可以删除或清空存档。

把网页带走

导出 HTML 或 Markdown，通过 Foxdown 服务器保存网页附件和有权访问的媒体资源。

安装后，开始阅读

  1. 从 GitHub Releases 下载并解压安装包。
  2. 打开浏览器的扩展管理页，开启开发者模式，选择「加载已解压的扩展程序」，加载含 manifest.json 的文件夹。
  3. 按引导连接狐森账户或填写 API Key，选择模型并开启网页内容授权。
  4. 点击工具栏中的 Foxmind 打开侧边栏，再点击「总结当前页」。

摘要功能使用狐森模型服务，需要有效密钥、可用模型与额度。网页导出可独立使用。连接 Foxdown 后可发送下载任务。

标题和提取的文字会在用户主动请求摘要时发送至狐森模型服务。普通窗口的摘要存档在当前浏览器配置中共用，切换账户后仍可查看。阅读隐私政策
